# QuickMemo 퀵메모

> 누구나 즉시 열고 바로 적을 수 있는 가장 빠르고 간단한 웹 메모장

QuickMemo는 무가입, 무복잡, 무지연을 원칙으로 하는 반응형 웹 메모장입니다. 모든 데이터는 사용자의 기기(브라우저 로컬 스토리지)에만 안전하게 저장되며, 오프라인 상태에서도 모든 기능을 완벽하게 지원합니다.

## ✨ 핵심 기능 (Key Features)

- **즉시 생성 및 편집**: 페이지를 열자마자 `+` 버튼을 눌러 바로 메모 작성을 시작할 수 있습니다.
- **자동 저장**: 사용자가 입력을 멈추면 1초 뒤 자동으로 내용이 저장되어 데이터 유실 걱정이 없습니다.
- **오프라인 우선 (Offline-First)**: 인터넷 연결 없이도 메모를 생성, 조회, 수정, 삭제하는 모든 기능이 정상적으로 동작합니다.
- **간단한 서식**: **굵게(Bold)**, *기울임(Italic)*, 순서 있는/없는 목록 등 기본적인 서식 기능을 지원합니다.
- **메모 정렬**: 메모 목록을 '최신순' 또는 '제목순'으로 쉽게 정렬할 수 있습니다.
- **휴지통 및 복구**: 삭제된 메모는 30일간 휴지통에 보관되며, 언제든지 복구하거나 영구 삭제할 수 있습니다.
- **반응형 디자인**: 데스크톱과 모바일 환경 모두에서 최적화된 UI를 제공합니다.
- **인터랙티브 마스코트**: 귀여운 마스코트 '퀵모'가 랜덤한 시간에 응원 메시지를 보여주며, 클릭하면 화난 표정으로 바뀌는 등 재미있는 상호작용을 제공합니다.
- **가입 필요 없음**: 어떤 회원가입이나 로그인 절차도 없이 즉시 사용할 수 있습니다.

## 🛠️ 사용된 기술 (Tech Stack)

- **Frontend**: `React`, `TypeScript`
- **Styling**: `Tailwind CSS`
- **Data Storage**: `Browser LocalStorage`
- **Testing**: `Jest`, `React Testing Library`, `User Event`

## 🚀 사용 방법 (How to Use)

별도의 빌드나 설치 과정 없이 `index.html` 파일을 브라우저에서 열기만 하면 바로 사용할 수 있습니다.

1.  **새 메모 작성**: 우측 상단의 `+` 버튼을 클릭합니다.
2.  **메모 목록 보기**: 헤더의 '메모' 탭을 클릭합니다.
3.  **휴지통 보기**: 헤더의 '휴지통' 탭을 클릭합니다.
4.  **정렬 기준 변경**: 메모 목록 상단의 드롭다운 메뉴에서 '최신순' 또는 '제목순'을 선택합니다.
5.  **빠른 삭제**: 메모 목록의 각 항목에 마우스를 올리면 나타나는 휴지통 아이콘을 클릭하여 메모를 바로 삭제할 수 있습니다.

## ✅ 테스트 (Testing)

이 프로젝트는 `Jest`와 `React Testing Library`를 사용한 자동화된 테스트 케이스를 포함하고 있습니다. 테스트는 주요 기능의 회귀를 방지하고 코드의 안정성을 보장하기 위해 작성되었습니다.

- **실행 위치**: `__tests__` 디렉토리 내에 테스트 파일이 위치합니다.
- **테스트 범위**:
  - **`App.test.tsx`**: 메모 생성, 수정, 삭제, 복구 등 핵심 사용자 시나리오에 대한 통합 테스트.
  - **`Mascot.test.tsx`**: 마스코트의 랜덤 메시지 표시 및 클릭 상호작용에 대한 컴포넌트 테스트.
  - **`memoUtils.test.ts`**: 메모 내용에서 제목과 미리보기를 추출하는 유틸리티 함수에 대한 단위 테스트.

(프로젝트에 `package.json`과 테스트 스크립트가 설정되어 있다면 `npm test` 또는 `yarn test` 명령어로 테스트를 실행할 수 있습니다.)
